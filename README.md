# Солнечная система — интерактивный вояж

Одностраничный лендинг-путешествие по Солнечной системе: скролл-сторителинг
от Солнца до Нептуна с 3D-сценой и интересными фактами о каждой планете.

## Запуск локально

```bash
npm install
npm run dev      # dev-сервер (Vite)
npm run build    # продакшен-сборка в dist/
```

## Публикация на GitHub Pages

Репозиторий уже настроен: сборка собирается с относительными путями
(`base: './'` в `vite.config.js`), а в `.github/workflows/deploy.yml` лежит
готовый workflow.

1. Создайте репозиторий на GitHub и запушьте код:
   ```bash
   git remote add origin git@github.com:<ваш-логин>/<имя-репо>.git
   git push -u origin main
   ```
2. В настройках репозитория: **Settings → Pages → Source → GitHub Actions**.
3. При каждом пуше в `main` сайт автоматически соберётся и опубликуется
   по адресу `https://<ваш-логин>.github.io/<имя-репо>/`.

Альтернатива без Actions: выполнить `npm run build` и выложить содержимое
`dist/` на любой статический хостинг — относительные пути позволяют
размещать сайт в любой подпапке.

## Структура

- `index.html` — вся разметка и стили: хиро, 10 секций-остановок, финал
- `src/scene.js` — 3D-сцена и скролл-хореография камеры
- `public/fonts/` — локальные шрифты Unbounded + Manrope (кириллица + латиница)

## Техники

- Three.js: шейдерное Солнце (fbm-шум + френель), спрайтовая корона,
  полностью процедурные текстуры планет (многооктавный value-noise):
  континенты и ночные огни Земли (emissive), облачный слой, полосы газовых
  гигантов с доменным искажением, кратеры, кольца Сатурна,
  двухслойное атмосферное свечение (additive rim), Луна,
  пояс астероидов на InstancedMesh (1700 инстансов),
  звёздное небо + Млечный Путь из светящихся спрайтов
- Камера привязана к секциям DOM: остановки интерполируются по прогрессу
  скролла, кадр смещается в сторону, противоположную текстовой панели
- Детерминированная генерация (seeded RNG) — кадр воспроизводим
- Fallback при отсутствии WebGL (CSS-постер), поддержка
  `prefers-reduced-motion`, мобильная адаптация
- Производительность: 60 FPS, бандл ~130 КБ gzip, внешних ассетов нет
